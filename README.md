# Crypto Sentinel Pro — Fixed Self-Learning Edition

Corrected Kaggle paper-trading notebook with persistent GitHub learning for `fahadumrani/trader_agent`.

## Run
1. Upload `crypto_sentinel_self_learning_github_FIXED.ipynb` to Kaggle.
2. Enable Internet.
3. Create a fine-grained GitHub token restricted to this repository with **Contents: Read and write**.
4. Store it in Kaggle Secrets as `GITHUB_TOKEN` and attach it to the notebook.
5. Select **Run All**.

## Safety
Paper trading only. Never commit tokens, exchange credentials, passwords, wallet seeds, or personal financial data. Results do not guarantee profit.
